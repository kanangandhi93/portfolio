Exposure of EOL Apache Cocoon Framework & Unpatched CVEs

Scope: portal-fm1.[redacted-telecom].net & portal-fm2.[redacted-telecom].net
Classification: VRT: Known Vulnerabilities > Outdated Software

// 1. Executive Summary

During external perimeter reconnaissance across enterprise telecommunications management systems, two production facility portal clusters (eFRAMS3) were discovered running a legacy, end-of-life framework: Apache Cocoon 2.0.4 deployed on an unversioned Apache-Coyote/1.1 Tomcat backend.

Apache Cocoon has been officially retired with no active security updates. Version 2.0.4 suffers from multiple documented high-impact vulnerabilities, including critical XML External Entity (XXE) injection and SQL injection in core serializers. Furthermore, comparative edge testing revealed inconsistent Akamai WAF rules between cluster nodes, leaving the primary portal accessible without challenge.

// 2. Unpatched CVE Exposure in Apache Cocoon 2.0.4

The identified software version (X-Cocoon-Version: 2.0.4) is vulnerable to multiple public CVE advisories:

CVE ID Severity CVSS Vulnerability Summary
CVE-2023-49733 CRITICAL 9.8 Improper restriction of XML External Entity Reference (XXE) allowing remote file disclosure and SSRF.
CVE-2022-45135 HIGH 8.8 SQL Injection via improper neutralization of special elements in database serialization and SQL transformers.
CVE-2020-11991 HIGH 7.5 XXE Injection in StreamGenerator component processing untrusted XML inputs.
CVE-2025-24783 HIGH 7.5 Predictable PRNG generation for continuation IDs, enabling session hijacking attacks.
CVE-2003-1172 HIGH 7.5 Directory traversal vulnerability via view-source sample handlers exposing server filesystem.

// 4. Comparative Edge WAF Analysis (FM1 vs FM2)

A comparative matrix across cluster nodes demonstrated significant rule divergence at the Akamai edge layer:

Test Vector FM1 Node (Permissive) FM2 Node (Hardened) Finding

POST (empty body) 411 Length Required 411 Length Required Both hit identical Tomcat backend.

// 5. Security & QA Remediation Plan

  • 1. Decommission EOL Components: Migrate the enterprise portal away from unmaintained Apache Cocoon 2.0.4 to a modern, supported web framework.
  • 2. Unify Edge WAF Rules: Replicate the strict Akamai WAF Rule #18 policy active on FM2 across the FM1 cluster node to eliminate public exposure.
  • 3. Strip Disclosure Headers: Configure the edge reverse proxy tier to remove X-Cocoon-Version and Server: Apache-Coyote/1.1 before responses reach clients.
  • 4. Disable External XML Entities: Mandate disallow-doctype-decl = true in all XML processing pipelines to defeat XXE injection attempts.
