HIGH (CVSS 8.2) Authentication & Secrets Management Target: Global Hospitality Management System

Exposed OAuth2 Client Credentials in Client-Side JavaScript Bundle

Scope: Client-side SPA Production JavaScript Bundle
Status: Remediated & Verified

// 01. EXECUTIVE SUMMARY

Static analysis of a compiled React frontend bundle revealed hardcoded production environment variables containing confidential OAuth2 `client_secret` strings, client IDs, PingFederate SSO configurations, and internal gateway routes.

// 02. PROOF OF CONCEPT & REPRODUCTION FLOW

### 1. Credential Extraction from Bundle ```javascript // Extracted from compiled SPA client bundle (Sanitized) REACT_APP_CLIENT_ID: "[REDACTED_CLIENT_ID]" REACT_APP_GRANT_TYPE: "authorization_code" REACT_APP_CLIENT_SECRET: "[REDACTED_HIGH_ENTROPY_SECRET_64_CHARS]" REACT_APP_TOKEN_URL: "https://auth-api.[redacted-hospitality].com/v1/auth-service/token.auth" REACT_APP_API_URL: "https://internal-api.[redacted-hospitality].com/v1" ``` ### 2. Token Exchange Probe ```bash curl -s -D - "https://auth-api.[redacted-hospitality].com/v1/auth-service/token.auth" \ -H "Origin: https://app.[redacted-hospitality].com" \ -H "Content-Type: application/x-www-form-urlencoded" \ -X POST \ -d "grant_type=authorization_code&client_id=[REDACTED]&client_secret=[REDACTED]&code=probe&redirect_uri=https://app.[redacted-hospitality].com" ``` **Response:** Returned HTTP 400 with `invalid_grant`, confirming client credentials and origin headers are accepted and verified by the gateway.

// 03. BUSINESS IMPACT & REGULATORY EXPOSURE

Enables arbitrary token minting, internal SSO infrastructure mapping, and potential impersonation of corporate client applications.

// 04. REMEDIATION & QA ENGINEERING GUIDANCE

1. **Migrate to OAuth 2.0 PKCE:** Public client applications (such as React SPAs and mobile apps) must never hold confidential client secrets. Implement RFC 7636. 2. **Immediate Credential Invalidation:** Revoke and rotate all exposed client IDs and secret keys across staging and production. 3. **Automated Secret Detection:** Embed automated scanners (TruffleHog, GitGuardian) into pre-commit hooks and GitHub Actions.
