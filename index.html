CRITICAL (CVSS 9.1) API Security / BOLA

Broken Access Control in Multi-Tenant API

Identified horizontal privilege escalation where modifying tenant identifiers (`org_id` / `tenant_uuid`) in downstream microservice endpoints bypassed tenant isolation, leaking sensitive cross-company customer databases.

Vulnerability: BOLA / IDOR in Tenant Scope
Target Scope: REST API `/api/v2/tenants/{id}/billing`
Remediation: JWT Tenant Claim Claims Binding + Row Level Security
Burp Suite API Testing BOLA Multi-Tenancy
HIGH (CVSS 8.6) Cloud & Data Exfiltration

Unauthenticated Cloud Storage Exfiltration

Discovered permissive cloud storage ACLs and unauthenticated public bucket endpoints exposing production database snapshots, KYC verification documents, and invoices via automated fuzzing of asset URL patterns.

Vulnerability: Public Object Storage Misconfiguration
Target Scope: S3 / Cloud Storage Storage Bucket API
Remediation: Block Public Access + Signed Presigned URLs
Cloud Security AWS S3 Fuzzing OWASP Top 10
HIGH (CVSS 8.2) Auth / Secrets Leak

Hardcoded OAuth Secrets & Client Invalidation

Extracted embedded OAuth client secrets and developer keys compiled into production client-side JavaScript bundles and staging configs, facilitating unauthorized token minting and API impersonation.

Vulnerability: Exposed OAuth Client Credentials
Target Scope: SPA Production JS Bundle & Auth Flow
Remediation: Migrated to OAuth 2.0 PKCE + Secrets Vault
OAuth 2.0 JavaScript PKCE Static Analysis
HIGH (CVSS 7.8) Logic & Session Integrity

Session Integrity & Race Condition Flaws

Uncovered concurrent request race conditions in checkout coupon redemption and incomplete server-side session revocation during privilege elevation and password reset flows, enabling stale token reuse.

Vulnerability: Time-of-Check to Time-of-Use (TOCTOU) & Stale Session
Target Scope: Checkout API & Auth Session Store
Remediation: Atomic Distributed Locks + Central Session Blacklist
Turbo Intruder Race Conditions Business Logic Session Security
