Broken Access Control in Supplier Insights API

Target: Enterprise E-Commerce Platform

Authorization relied entirely on client-controlled HTTP header (Supplier-Id). Modifying this header allowed authenticated users to access confidential sales metrics and insights of arbitrary suppliers.

Flaw: Header-Based BOLA / IDOR
Scope: POST /api/insights/dashboard
Fix: Server-Side Session Binding
📄 Markdown

File Storage API Complete Data Exposure

Target: International Ride-Hailing Platform

Combined missing authentication on file read operations with a CORS wildcard (*), enabling zero-interaction cross-origin exfiltration of KYC identity documents and driver licenses.

Flaw: Unauthenticated IDOR + CORS Wildcard
Scope: GET /api/v1/files/{uuid}
Fix: Strict Auth + Pre-Signed URLs
📄 Markdown

Public Exposure of Internal PKI Trust Chain

Target: Multinational Retail Conglomerate

JWKS x5c parameter exposed internal Certificate Authority URLs. Root CA, Sub CA, 15KB CRL, and active OCSP responders were publicly accessible, revealing internal hostnames and JWT keys.

Flaw: Public Internal PKI Trust Chain
Scope: JWKS URI + Public PKI Endpoints
Fix: Remove x5c + Firewall PKI Server
📄 Markdown

Hardcoded OAuth2 Client Credentials in SPA

Target: Global Hospitality System

Production/UAT React single-page app bundle exposed confidential OAuth2 client_secret and gateway endpoints, enabling unauthorized token exchange and internal API access.

Flaw: Exposed OAuth2 Client Secret
Scope: Public main.[hash].js Bundle
Fix: Migrate to OAuth 2.0 PKCE Flow
📄 Markdown

Session Replay & Dynamic Account Switching

Target: Healthcare & Genetics Platform

Session identifiers lacked environment binding. Modifying the cookie caused the server to overwrite the active session cookie in the browser, triggering seamless unauthorized account switching.

Flaw: Session Overwrite & Lack of Binding
Scope: Cookie: sessionid=[REDACTED]
Fix: Device/IP Binding + Regeneration
📄 Markdown

Open GraphQL User Registration & JWT Minting

Target: Pan-African Mobile Banking Platform

Production CMS backend exposed an unrestricted GraphQL mutation that created auto-confirmed user accounts, minting valid production JWT tokens across 1,350+ live accounts.

Flaw: Open Registration on Production CMS
Scope: POST /graphql (register mutation)
Fix: Disable Public Mutations + Verify
📄 Markdown

Missing Server-Side Enforcement of Terms Acceptance

Target: EdTech & Online Learning Platform

Registration endpoint relied on client-side controls for consent. Submitting has_accepted_terms_and_condition: false still registered the user and issued valid JWT credentials.

Flaw: Client-Side Only Consent Validation
Scope: POST /api/users/register/
Fix: Server-Side Schema Boolean Assertion
📄 Markdown

Direct Origin Access & WAF Bypass via Header IP Disclosure

Target: Global Connected Vehicle & EV Enterprise

CDN latency profiling headers leaked backend origin IPs. Direct connections completely bypassed the Akamai WAF perimeter, enabling unthrottled token attacks and a DoS crash via client proxy headers.

Flaw: Origin IP Leak + Direct Ingress Access
Scope: auth.[redacted].com & owner-api.[redacted].com
Fix: Origin Shielding Firewall + Header Stripping
